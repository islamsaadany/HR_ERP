Spec 038 · learning manager nav

One click to Manage Learning

An appointed learning manager gets their own gold sidebar entry that goes straight to the module, carrying the same gold count the rest of the sidebar uses. HR’s sidebar does not change at all. Illustrative content throughout.

1 Their sidebar

It sits in the gold block at the bottom, where Admin sits today, separated from their ordinary employee nav by the same divider. Manage Learning, not “Learning” — they already have a Learning item above it for the courses they take themselves, and two entries with one word would be a worse problem than an extra click ever was.

2 What the badge counts

The same thing the gold badge on the admin home counts today: resources employees have suggested and nobody has reviewed. It is the only thing in Learning that waits on a person, which is what a badge is for — a number that never falls to zero stops being read.

3 The dead end this closes

Once she has a direct door, the single-section admin home is a page she can only reach by accident — a bookmark, or the “← Admin” link at the top of the Learning page. Both would land her on one row she just came from.

Today

Sidebar Admin → a page with one row → Learning

Two clicks, and a page that exists only to be passed through.

Proposed

Sidebar Manage Learning → Learning

One click. And /admin sends a learning manager straight here too, so a stray bookmark cannot strand them.

also the “← Admin” link at the top of the Learning page is hidden for them — there is nothing above it any more.

Which makes the one-section admin home unreachable, so it goes. That is a simplification, not extra work: a branch nobody can open is worse than no branch. HR’s admin home is untouched.

What I’m assuming — correct me and I’ll change it

  • Only appointed learning managers get the entry. HR’s sidebar is exactly as it is today — their door is Admin.
  • It replaces their Admin entry rather than sitting beside it, and /admin redirects them to /admin/learning.
  • The badge counts suggested resources awaiting review — the same figure the admin home shows now. Nothing else in Learning waits on a person.
  • Gold, below the divider, in the same block as Admin / Incentive / Payments — that block has meant “a door you hold, not a page everyone has” from the start.
  • Called “Manage Learning” so it cannot be confused with their own Learning above it.
  • Nothing about permissions changes. Every page and action still asks the same one derivation; this is a shortcut, not a grant.
