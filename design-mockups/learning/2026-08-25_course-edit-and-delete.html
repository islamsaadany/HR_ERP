Learning · course housekeeping

Renaming and deleting a course

Two things the module has never offered: there is no way to change a course's name after you create it, and no way to throw a course away — so the drafts pile up. Both already work on the server; nothing exists on screen to reach them. This is the proposed screen work, for your sign-off before anything is built. Illustrative content throughout.

1 A quiet menu on each course in the list

The Learning list is where you'd clear out drafts, so the two controls live there — one small ⋯ on the right of each row, outside the link, so the row still opens the course when you click it. Nothing else about the row changes.

2 Delete asks once, in the row itself

No pop-up. The row turns into a confirmation that names the course and says what goes with it, because a delete you can't undo should read like a sentence rather than a dialog you dismiss on reflex. Cancel puts the row straight back.

3 A course people have started is refused

This rule is already written on the server and it does not change: deleting a course somebody has worked through would destroy their record of having done it. The refusal says who and what to do instead.

31 people have started “Onboarding: week one”, so deleting it would destroy their record. Pause it instead — nobody can open it, and everything they've done is kept. Close

Same wording wherever Delete is offered. Pausing and returning to draft stay where they are, on the course's own page.

4 Renaming: the same details you typed when you created it

Rename opens the course's name and one-line description — the two things the create form asks for — right where you are. It is the same small panel from the list and from the course page, so there is one place a course's name is changed, not two.

What I need you to confirm

  1. The menu, not a row of buttons. Two extra buttons on every row would compete with the course title; a single ⋯ keeps the list looking exactly as it does now.
  2. One course at a time. You said the drafts need clearing — this is two clicks each, with no page to leave. If you would rather tick several and delete them together, say so now and I'll mock that instead; it adds a selection mode to the list, which is why I haven't assumed it.
  3. Delete is refused for a course anyone has started, published or not, and pausing is offered instead. Deleting is otherwise allowed at any status — a published course nobody ever opened can go.
  4. Rename edits the title and the description only. Everything else about a course is already editable on its own tabs.
