Reimbursed records — dates & Finance edit

Two changes to the Payments table, reimbursed rows only. The approved date already shows in its column; this adds a clear Reimbursed on date and lets Finance correct a reimbursed record.

  • New "Reimbursed on" column — the transfer date, shown beside the existing "Approved" date so both are visible at a glance ("—" while a claim is still awaiting payment).
  • Edit on reimbursed rows — an Edit link opens an inline form (amount + reimbursement date → Save / Cancel), Finance-only. Fixes a mistyped date or amount without leaving the page.

Proposed

Row 1 = awaiting payment (unchanged confirm form). Row 2 = reimbursed (read-only display + Edit). Row 3 = the same reimbursed row with Edit open.
