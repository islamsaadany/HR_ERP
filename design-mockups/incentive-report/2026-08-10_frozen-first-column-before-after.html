Freeze the first column

On wide tables, when you scroll sideways the first column (Client / Name) scrolls off with everything else, so you lose track of whose row you're reading. Freezing it pins it in place while the rest scrolls.

Where it applies: the incentive report tables (first column = Client) and, if you want, the employee registry (first column = Name). The pinned column carries the same background as the table so rows read cleanly, with a subtle right-edge shadow that only appears meaningful once you scroll.
