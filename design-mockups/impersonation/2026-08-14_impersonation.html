How it behaves
  • Who: only a Super User sees “View as”, and can’t impersonate another Super User.
  • No logout: your real session stays; a cookie flags who you’re viewing. The banner is always visible so it’s unmistakable.
  • Employee shell: admin/incentive nav disappears while impersonating — you see exactly what they see (so no real salaries leak from admin screens).
  • Reusable: use it any time to walk an employee through their own benefits, time-off, or profile.
  • Acting as them: to be decided — view-only, or allowed to submit (e.g. file a claim) as them for live demos. See my question below.
