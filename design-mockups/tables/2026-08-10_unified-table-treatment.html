One consistent table treatment — for every data table

Applied the same way to the registry, the incentive report, and the rest, whatever the first column is called. Three behaviors bundled together:

Full width — fills the screen (page-level) Frozen header row — stays on vertical scroll Frozen first column — stays on horizontal scroll

Scroll any direction — the header row and the first column stay put (first column carries a soft right-edge shadow). At full page width, sideways scrolling is rarely needed at all.

How it rolls out: a shared table style (not six hand-made copies) so every table looks and behaves identically. Full width is applied per page; the frozen header + frozen first column apply to every data table. The registry and incentive report already got full width — this adds the frozen header/column and brings the others (Directory, Admin Time-off, Benefit Release, …) into the same pattern.
