Reset passwords for selected employees

Adds a third option to the existing Passwords ▾ menu so HR can pick specific people instead of resetting everyone or only the blank ones. Nothing else on the registry page changes. Colours, type and component shapes are taken from the live tokens in globals.css; the real page uses Fraunces + Hanken Grotesk, substituted here with the same fallback stack the app declares.

Reset passwords for selected employees

Each person you pick gets a new temporary password and must choose their own the next time they sign in. You’ll get the list to download once.

Active employees only
3 selected
  • Your own account never appears in the list, so you can’t lock yourself out.
  • The chip tells you who already has a working password, so a reset is a deliberate choice rather than a surprise.
  • Select all applies to what the search currently shows, and the count says so.
  • With nothing ticked the confirm button reads Reset 0 passwords and is disabled.
  • A confirmation step follows the button, matching the other destructive admin actions.
