Admin attention signals

Three changes, no restyling: Benefits & Time-Off moves to the top of the admin home, the two cards in it carry a needs-attention pill that counts more than claims, and the Benefits page's tabs carry the same marks so the signal survives the click. Cards, colours, spacing and hover behaviour are untouched.

The mark survives the click

inside /admin/benefits
Claims 3 Medical 2 Benefits Catalogue Amounts

The Claims tab already carries a gold count of claims to review. Medical gains the same device in red, counting only the rows its own "Needs attention" chip counts — an over-charge or a cover that ended. Click through and the matching filter chip is already applied, so the badge, the rail tile and the filtered list all agree on the same number.

Red is reserved for money that is wrong; gold means someone is waiting. That is the same split the two panels already use, so nothing new has to be learned.

Mockup only — no components changed. Cost: the admin home currently runs two count queries; this adds two more (medical exceptions, pending leave). Both are cheap counts on indexed columns, and both are wrapped the way the existing ones are — if the query fails the pill is simply omitted, never a broken admin home.
