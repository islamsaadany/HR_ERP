Benefit release table — proposed changes

Three changes on the release table for Summer Allowance (Part-time). Employment type comes straight from each employee's record — nothing new is computed. Type values below the "no part-time amount set" rows are illustrative for rows whose real type I can't see from the screenshot.

  • 1 · New "Type" column after Tenure — an FT / PT badge so you can see at a glance who is part-time.
  • 2 · Status wording — the "Needs attention —" prefix is dropped; only the real reason remains (e.g. "No part-time amount set", "< 6 months — not yet eligible").
  • 3 · "Not released" is now red for clarity.
